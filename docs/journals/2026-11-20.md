# Journal 2026-11-20 — cài skill pack reverse-skill theo convention có sẵn

## Việc đã làm

Cài [zhaoxuya520/reverse-skill](https://github.com/zhaoxuya520/reverse-skill) (MIT) lên
máy này và ghi lại **công thức cài** vào repo để máy mới dựng lại được.

| Đích | Dạng | Nội dung |
|---|---|---|
| `~/juju-projects/repo/reverse-skill` | clone | pack, commit `b972ad0` |
| `repo/juju-agent-skills/skills/reverse-skill` | symlink tương đối `../../reverse-skill/skills` | omp (`skills.customDirectories`) + pi (`skills[]`) |
| `~/.claude/skills/reverse-skill` | symlink tuyệt đối | Claude Code + omp (`skills.enableClaudeUser`) |

`~/.pi/agent/settings.json` **không** bị sửa: `skills[]` vốn đã trỏ
`repo/juju-agent-skills/skills` cho toàn bộ `jj-*`, nên symlink mới được nhặt cùng lượt.

Script thực hiện: `scripts/install-reverse-skill.sh` (idempotent, `--dry-run`, `--ref`,
`--client agents|claude|all`, `--dir`). Chạy hai lần liên tiếp → cùng trạng thái.

## Quyết định: đi theo convention của `juju-agent-skills`

Bản đầu của script tự mở đường đăng ký thứ hai: symlink vào `~/.omp/agent/skills` và
thêm một path tuyệt đối vào `.skills[]` của pi. Sai hướng — `jj-*` không làm vậy, và
path tuyệt đối trong `settings.json` khiến bản mirror `config/settings.json` không dựng
lại được ở `$HOME` khác.

Convention thật trên máy này chỉ có hai thư mục:

| Thư mục | Ai đọc | Cấu hình |
|---|---|---|
| `repo/juju-agent-skills/skills/` | omp, pi | omp `skills.customDirectories`; pi `skills[]` |
| `~/.claude/skills/` | Claude Code, omp | omp `skills.enableClaudeUser: true` |

`argos-qa`, `juju-chef`, `daily-summary` là tiền lệ: skill ở repo riêng, chỉ cần symlink.
`reverse-skill` theo đúng kiểu đó.

Đo lại sau khi bỏ hai đường thừa:

- pi 1.5.2 `loadSkills({skillPaths: ['.../juju-agent-skills/skills']})` → 21 skill,
  có `reverse-skill-router`, `diagnostics: 0`.
- omp 19.0.1 `omp -p` hỏi catalog → `reverse-skill-router`; `apk-reverse` **không**
  resolve (đúng: sub-skill không được đăng ký riêng).
- `ls ~/.omp/agent/skills | grep -v '^ak-'` → rỗng, tức không còn symlink riêng nào.

Symlink trong `juju-agent-skills` để **tương đối** vì nó nằm trong một git work tree;
tuyệt đối hoá thì clone ở path khác sẽ hỏng. Script chọn tương đối khi thư mục đích là
git repo, tuyệt đối khi không (`~/.claude/skills`).

## Quyết định: link thư mục `skills/`, không link từng skill con

Pack có 43 thư mục con trực tiếp có `SKILL.md` (45 nếu tính cả 2 cái lồng sâu:
`pentest-tools/src-hunter`, `reverse-engineering/dsl-vm-reverse`). `skills/SKILL.md` là
router, `skills/config/routing.json` là bảng route duy nhất.

pi `dist/core/skills.js` load theo kiểu: gặp `SKILL.md` trong một thư mục → nạp thư mục
đó là **một** skill rồi `return`, **không** đệ quy tiếp vào trong. Đo bằng chính code của
pi 1.5.2:

```js
loadSkills({cwd, agentDir: '~/.pi/agent', skillPaths: ['<pack>/skills'], includeDefaults: false})
// → count: 1, diagnostics: []
// → reverse-skill-router  ~/juju-projects/repo/reverse-skill/skills/SKILL.md
```

| Cách | Entry trong catalog | Token mô tả | Hệ quả |
|---|---|---|---|
| link `skills/` | 1 | ~90 | 45 mô tả chuyên môn không nằm trong prompt; router đọc `routing.json` khi cần |
| link từng con | 45 | ~1.789 (đo: 7.159 ký tự) | trả tiền mỗi request; dễ trùng tên skill khác |

Chọn cách đầu. Sub-skill vẫn đọc được: router trả đường dẫn tương đối
(`skills/apk-reverse/SKILL.md`), agent đọc file đó ngay trong thư mục pack.

## `--dry-run` hỏng trên máy chưa clone — đã sửa

Hai lỗi tìm được khi thử `--dry-run` với `REVERSE_SKILL_DIR` chưa tồn tại:

- Bước validate frontmatter chạy vô điều kiện nên abort `exit 1` dù `git clone` chỉ được
  *in*. Sửa: chỉ validate khi `[ -f "$SKILL_ROOT/SKILL.md" ]`, thiếu thì in
  `→ (dry-run) pack chưa tồn tại — bỏ qua kiểm frontmatter`.
- `realpath --relative-to` fail khi pack chưa tồn tại → thay `realpath -m`.

Kiểm lại: `REVERSE_SKILL_DIR=/tmp/rs-none-$$ ... --dry-run` → exit 0, in đủ kế hoạch,
**không** tạo `/tmp/rs-none-*`, không rác stderr. Guard còn nguyên: đích tồn tại nhưng
không phải git repo → exit 1; `--client bogus` → exit 1.

## Không cài toolchain

`skills/tool-index.md` bị gitignore (sinh theo máy). Chạy
`skills/scripts/refresh-tool-index.sh` trên máy này: **35 tool khai báo, 5 có sẵn**
(`python3` 3.14.4, `node`/`npm`/`npx` v24.22.0, + runtime). Thiếu: `jadx`, `apktool`,
`adb`, `frida`, `r2`, `ghidra`, `burp`, `nmap`, `sqlmap`, `ffuf`, `hashcat`, `binwalk`,
`java`, `pipx`, `graphviz`, `plantuml`, …

Cố ý **không** chạy `bootstrap-reverse.sh`: nó tải binary từ GitHub release, build
radare2 từ source, và có thể đăng ký MCP server. Đó là side effect thuộc loại phải được
duyệt riêng, không phải hệ quả phụ của "cài skill". Script cài chỉ cảnh báo nếu thiếu
`tool-index.md` và in lệnh gợi ý.

## Bẫy: router ghi `work/` vào cwd

`master-route.sh` mặc định `--project-root` = cwd. Chạy từ `~` hay `~/juju-projects`
sinh `work/master-route-<ts>/route-scope.md` ở đó — với `~/juju-projects` thì đó là
thư mục **không** gitignore (`work/` chỉ bị ignore trong pack). Muốn artefact nằm trong
dự án đang làm: `--project-root <dir>` tường minh.
