# Journal 2026-10-22 — port MCP servers từ omp sang pi

## Việc đã làm

Đồng bộ 6 MCP server từ `~/.omp/agent/mcp.json` sang pi. Trạng thái cuối:

- `~/.pi/agent/mcp.json`: `devin` (giữ nguyên), `redmine`, `gitlab`, `semble`, `atlassian`, `anymd`.
- `~/.pi/agent/mcp-adapter.json` (mới): `api-mnd-filesystem`.

## Vì sao `api-mnd-filesystem` không nằm trong `mcp.json`

`@modelcontextprotocol/server-filesystem` đọc client `roots` và thay thế thư mục trong
args. Cả Pi built-in MCP lẫn `pi-mcp-adapter` đều gửi **session dir của Pi** làm root →
server sẽ serve session dir thay vì `/mnt/api_mnd`.

Fix chuẩn là `"roots": false`, nhưng key này chỉ tồn tại trong adapter-native config —
`translatePiMcpServer` drop nó vào `ignored` khi gặp trong `mcp.json` (xem
`~/.pi/agent/npm/node_modules/pi-mcp-adapter/dist/config.js`). Precedence:
`~/.pi/agent/mcp-adapter.json` (pi-global, không shared) thắng `~/.pi/agent/mcp.json`.

Entry trong `mcp-adapter.json`:

```json
"api-mnd-filesystem": {
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "/mnt/api_mnd"],
  "roots": false
}
```

## Chi tiết từng server

| Server | Ghi chú |
|---|---|
| `redmine` | `uvx --from mcp-redmine`; env gồm `REDMINE_API_KEY` (hiện là literal, check lại nếu redmine fail), `REDMINE_URL=https://pmis.vietinfo.tech:8080`, `REDMINE_DANGEROUSLY_ACCEPT_INVALID_CERTS=1` |
| `gitlab` | `~/gitlab.sh` — eval `GITLAB_API_URL`/`GITLAB_PERSONAL_ACCESS_TOKEN` từ `~/.bashrc`, `npx @zereight/mcp-gitlab` |
| `atlassian` | `~/atlassian.sh` — eval `JIRA_URL`/`JIRA_USERNAME`/`JIRA_API_TOKEN` từ `~/.bashrc`, `uvx mcp-atlassian` |
| `semble` | `uvx --from semble[mcp]` |
| `anymd` | binary local `~/.npm-global/.../anymd mcp`, `enabled: true`, `timeout: 120` (giây → `requestTimeoutMs`) |

## Verify sau khi restart pi

- `list_allowed_directories` của filesystem phải trả `/mnt/api_mnd`. Nếu trả session dir
  → phiên bản server-filesystem đổi hành vi roots, check lại.
- Redmine fail auth → thay literal `"REDMINE_API_KEY"` bằng key thật hoặc `${VAR}` nếu
  loader hỗ trợ interpolation.

## Precedence map (tham khảo `docs/servers.md` của pi-mcp-adapter)

1. `.mcp.json`, `~/.config/mcp/mcp.json`, `~/.agents/mcp.json` (shared/imports)
2. `~/.pi/agent/mcp.json` (Pi native)
3. `~/.pi/agent/mcp-adapter.json` ← adapter overrides, thắng các shared sources
4. `.pi/mcp-adapter.json` (project, cao nhất)
